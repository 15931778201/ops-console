### 2. 数据库模型（Prisma Schema）

| 模型 | 说明 | 关键字段 |
|------|------|----------|
| User | 用户表 | email, phone, planId, status |
| CreditAccount | 积分账户 | balance, bonusBalance, monthlyQuota |
| CreditTransaction | 积分流水 | type, amount, balanceAfter, referenceId |
| Order | 订单表 | orderNo, status, channel, amountCents |

### 3. API 端点

#### 认证 API（`/api/auth`）
- `POST /register` - 用户注册（支持邀请码）
- `POST /login` - 用户登录
- `POST /refresh` - 刷新令牌
- `POST /logout` - 用户登出

#### 账户 API（`/api/account`）
- `GET /` - 获取账户信息
- `GET /credits` - 获取积分信息
- `GET /transactions` - 获取积分流水

#### 计费 API（`/api/billing`）
- `POST /pre-deduct` - 预扣积分（幂等）
- `POST /confirm` - 确认消费
- `POST /rollback` - 回滚积分
- `POST /check-access` - 检查套餐权限

#### 支付 API（`/api/payment`）
- `GET /plans` - 获取套餐列表
- `POST /create-order` - 创建订单
- `GET /orders` - 获取订单列表
- `POST /notify` - 支付回调

#### 邀请 API（`/api/invite`）
- `GET /my-code` - 获取我的邀请码
- `GET /stats` - 获取邀请统计
- `GET /list` - 获取邀请列表

#### 管理 API（`/api/admin`）
- `GET /users` - 获取用户列表
- `GET /orders` - 获取订单列表
- `POST /adjust-credits` - 调整积分

### 4. 核心功能实现

#### 积分扣费流程（预扣 + 回滚）
```
用户操作 → 预扣积分 → 本地处理 → 成功确认 / 失败回滚
```

- Redis 幂等键防止重复扣费
- 数据库事务保证一致性
- 处理失败自动回滚

#### 邀请奖励机制
```
注册时填写邀请码 → 立即给被邀请人发奖 → 等待触发条件 → 给邀请人发奖
```

- `inviteeUserId` 唯一约束防止自邀/重复绑定
- 奖励积分单独分账（bonusBalance），不随月度重置清零

## 二、技术栈

- **框架**: Express.js
- **数据库**: PostgreSQL + Prisma ORM
- **缓存**: Redis（会话/幂等/限流）
- **认证**: JWT（Bearer Token）
- **验证**: Zod
- **安全**: bcrypt密码哈希、helmet安全头、CORS、速率限制

```bash
npm install
npm run db:generate
npm run db:push
npm run dev
```

## 五、与前端对接

### API 客户端配置

前端需要配置 API 基础路径：

```typescript
// src/lib/api-client.ts
const API_BASE_URL = process.env.NEXT_PUBLIC_API_URL || 'http://localhost:3001/api';

export async function apiCall(endpoint: string, options: RequestInit = {}) {
  const token = getAccessToken(); // 从 AuthContext 获取
  
  return fetch(`${API_BASE_URL}${endpoint}`, {
    ...options,
    headers: {
      'Content-Type': 'application/json',
      ...(token && { Authorization: `Bearer ${token}` }),
      ...options.headers,
    },
  });
}
```

### 需要对接的模块

1. `AuthContext` - 调用 `/api/auth/*` 端点
2. `CreditContext` - 调用 `/api/billing/*` 端点
3. `PlanContext` - 调用 `/api/payment/plans` 端点
4. `useCreditGuard` - 调用 `/api/billing/pre-deduct` 端点
